# Language Models from Scratch

Experimental small language models implemented with PyTorch.

## Projects

- Transformer and attention mechanisms
- Custom BPE tokenization
- Japanese language model training
- 30M and 60M parameter experiments
- Chat fine-tuning and evaluation
- GPU training experiments

## Hardware

- NVIDIA RTX 3060 Laptop GPU (6GB VRAM)
- WSL2 Ubuntu
- PyTorch

## Code

- `model.py`: Language model implementation
- `step4_attention.py`: Attention mechanism
- `bpe_tokenizer.py`: Custom tokenizer
- `train_japanese_base_v2.py`: Japanese model training
- `chat.py`: Chat interface

## Notes

Large datasets, model checkpoints and virtual environments
are excluded from this repository.

This is an experimental learning project, not a production LLM.
